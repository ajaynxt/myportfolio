Website speed basics: what to fix before redesigning

A practical website performance checklist covering image sizes, fonts, JavaScript, caching and mobile testing.

← All insightsDiscuss a project ↗

Start by measuring the current experience

Test important pages on mobile and desktop with PageSpeed Insights. Look at Core Web Vitals and the specific diagnostics rather than chasing a single score. Record the page tested and retest after each meaningful change.

1. Resize and compress images

Use images close to their displayed dimensions, choose modern formats such as WebP or AVIF where supported, and compress large files. Set width and height attributes to reduce layout shifts. Lazy-load below-the-fold images, but do not lazy-load the main hero image if it is the Largest Contentful Paint element.

2. Keep fonts under control

Use a small number of font families and weights. System fonts can be a fast option. If web fonts are important to the design, load only the weights used and consider preloading the most critical font file.

3. Reduce unnecessary JavaScript

Remove scripts and libraries that do not support a real user task. Defer non-critical scripts, avoid loading heavy animation code on every page and keep third-party widgets to a minimum.

4. Improve delivery and caching

Use a reliable host or CDN, enable compression and set sensible cache headers for static assets. Long-lived assets should use versioned filenames so updates can be delivered safely.

5. Protect mobile usability

Check that the first screen renders quickly on a typical mobile connection. Avoid oversized hero media, layout shifts, intrusive popups and buttons that are difficult to tap.

6. Retest after changes

Change one category at a time, test the same URLs and compare field data when available. Lab tests are useful for diagnosis, while real-user data shows how visitors experience the site over time.

Speed work should preserve readability, accessibility and conversion paths. A fast page that hides the contact action or breaks the content is not a better website.
